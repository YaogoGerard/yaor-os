# Desktop Modes

## Classic / Windows-like
Panneau principal, menu d'applications, fenêtres flottantes et interaction traditionnelle.

## macOS-like
Barre supérieure, dock, fenêtres flottantes et organisation centrée sur les applications.

## Tiling
Fenêtres organisées automatiquement, navigation clavier, espaces de travail et raccourcis configurables.

Les trois modes utilisent le même Desktop Core.
