# HRS — Hardware Requirements Specification

YAOR étant un système généraliste, les exigences matérielles seront définies progressivement.

## HRS-HW-001 — Architecture CPU
La première cible DEVRAIT être x86_64.

## HRS-HW-002 — GPU
Le système DEVRAIT fonctionner avec les GPU supportés par la pile graphique Linux sélectionnée.

## HRS-HW-003 — Input
Le clavier et la souris DEVRAIENT être supportés via la pile d'entrée Linux sélectionnée.

## HRS-HW-004 — Virtualisation
La plateforme de développement DOIT pouvoir être testée dans une machine virtuelle telle que QEMU.

## HRS-HW-005 — Extension des plateformes
D'autres architectures et plateformes pourront être ajoutées après stabilisation de la cible initiale.
