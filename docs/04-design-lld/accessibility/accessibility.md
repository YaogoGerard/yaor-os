# Accessibility Engine — LLD

```text
Accessible element -> Information extraction -> Normalization -> Language processing -> Translation -> Mooré TTS -> Audio
```

Le moteur doit pouvoir recevoir les événements de pointeur et demander les informations accessibles correspondant à l'élément ciblé.

Si aucun contenu accessible n'est disponible, une stratégie alternative telle que l'OCR pourra être utilisée lorsqu'elle est implémentée.
