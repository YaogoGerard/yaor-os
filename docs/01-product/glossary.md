# Glossary — YAOR OS

| Terme | Définition |
|---|---|
| YAOR | Nom du système d'exploitation du projet. |
| Userland | Ensemble des composants exécutés hors du noyau. |
| Compositor | Composant chargé de composer les surfaces graphiques. |
| Desktop Core | Moteur central du bureau YAOR. |
| Profile | Ensemble de paramètres définissant une expérience de bureau. |
| Plugin | Composant extensible pouvant ajouter une fonctionnalité au bureau. |
| Existing Component | Projet externe réutilisé par YAOR. |
| YAOR Component | Composant développé spécifiquement pour YAOR. |
| Caméléon | Architecture permettant de modifier l'expérience du bureau par configuration. |
| Accessibility Engine | Couche d'accessibilité de YAOR. |
| Mooré TTS | Synthèse vocale destinée au Mooré. |
| HLD | High-Level Design. |
| LLD | Low-Level Design. |
| C4 | Modèle de description d'architecture par niveaux de zoom. |
